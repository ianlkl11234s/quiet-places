新增左右各 45° 環繞；使用者要求旋轉後光影成立且保留強烈耶穌光。改 bounded volume raymarch，主 agent 修正焦散座標與加強光束，桌面兩端點及手機尺寸實看。保留原始 Git tag；使用者確認效果良好後，授權提交環繞、體積光與光束強度控制。
