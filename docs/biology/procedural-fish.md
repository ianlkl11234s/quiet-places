# 程序魚群製作頁（歷史基準）

2026-09-07 起，水光之間在 `codex/waterlight-long-fin-koi` 分支改製長鰭錦鯉；最新進度見[長鰭錦鯉製作頁](long-fin-koi.md)。下列參數和驗收保留為舊版紀錄。

> 狀態：水光之間的即時視覺系統。它沒有指定物種、外部模型或生物形態資料；所有形狀、材質、速度與 steering 均為感知近似，不是魚類重建或物理模擬。

## 範圍與來源

- 場景脈絡、光路與產品限制見[水光之間](../scenes/waterlight.md)。網站入口為 `src/places/waterlight/FishSchool.ts`，由 `src/places/waterlight/index.ts` 建立並隨場景 update/dispose。
- 沒有 Blender 母檔、GLB、貼圖或下載資產。`FishSchool.ts` 以 Three.js 幾何與固定 seed `0x51f15` 直接生成九尾魚；其可重建來源即該程式檔。
- 「魚」僅是抽象視覺元素，未聲稱物種、年齡、體型、習性或生物事實。本次未新增生物研究或外部參考。

## 模型、材質與座標

- 每尾以拉長的 `SphereGeometry` 當身體，三角形幾何構成背鰭、胸鰭與雙葉尾，另有兩眼；身長在 0.25–0.50 scene units 間以固定亂數決定。這是簡化輪廓，不含鱗片、骨架、皮膚或解剖結構。
- 七尾採灰白色、兩尾金色；`MeshStandardMaterial` 以低強度 emissive 保持轉向背光時的可讀性，鰭使用半透明雙面材質。這些是顯示調校，非真實魚體反射、透光或發光。
- 魚頭／前方為本地 `+X`。群游邊界是 `x=-2.8..2.8`、`y=2.4..5.7`、`z=-3..1.5` 的場景座標；模型沿目前速度向量旋轉，沒有資產座標轉換。

## 動作與程式入口

- 每尾保有位置、速度、個別 phase 與 0.22–0.34 scene units/s 的基礎速度。每幀將 dt 限制在 0.05 秒，計算鄰近聚合與 separation、連續 wander、受光區的輕微 attraction，以及邊界回轉，再以平滑插值更新方向。
- 尾部以 elapsed、activity 和個別 phase 驅動 `rotation.y`；這是固定數學擺動，並非 shader、骨架、肌肉、避障、流體或自主群游模型。`dt=0` 不會推進位置。
- dispose 時走訪並釋放群組的幾何與材質，然後自 scene 移除。水面、焦散、光束與魚的受光各自為視覺近似，沒有彼此完整的光線追蹤遮擋。

## 既有驗收與缺口

- `docs/VALIDATION.md` 的第一版本機紀錄：Node smoke 對九尾魚跑 3,000 幀／27,000 次有限值與活動邊界檢查，暫停時位置不變、dispose 後 scene children 為零；1280×720 與 390×844 瀏覽器中魚群可見，最終 error/warn log 為空。後續集合整合紀錄列出 `npm test` 17/17 與 build 通過。這些是既有本機證據，本次文件整理未重跑。
- 未驗證：M3 的完整產品驗收在場景規格仍未勾選；實體手機 FPS、熱、耗電與 GPU 記憶體；真實生物形態／行為；魚群與光束的深度遮擋及魚體焦散；正式部署。固定 seed 有利於重現，不代表自然行為。
