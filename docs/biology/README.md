## 新增生物的最小文件格式

每個新頁面至少記錄下列欄位；未知請直接寫「未知」或「未驗證」，不要以合理推測補齊。

```md
# 中文名／學名或系統名

## 狀態與範圍
- 場景、程式入口、資產位置、目前接入狀態。

## 來源與授權
- 生物事實來源、視覺參考、模型／貼圖／音訊來源及各自授權；未使用外部資產也要註明。

## 生物事實與美術近似
- 可由來源支持的形態或行為；另列造型、尺度、路徑、速度與物理的美術假設。

## 製作與轉換
- 母檔／可重建腳本、座標軸、單位、材質、骨架／動畫，以及 Blender 到網站的轉換。

## 驗收與缺口
- 已實做證據、實際 GLB／runtime／browser readback、效能與生物學限制；分開列出待驗收項目。
```

共同材質與光照規則見[材質與光照製作筆記](../MATERIALS_AND_LIGHTING.md)。

## 可重用動態契約

新增／修改生物時補下列資訊到該生物頁，既有未補項目視為未驗證，不猜測：

- 公式的程式檔／符號、每個變數的單位（秒、公尺、弧度、Hz）、有效範圍、dt 與 seed；例：相位形式 `2πft + φ` 中 f 為 Hz，但具體頻率必須來自該物種來源或明標美術校準。
- 移動速度與尾擺／鰭拍是否耦合、轉彎曲率與側傾、加減速／休息／群游狀態、避免規律同步的方法。
- 模型前向軸、尺度、骨架／clip 名稱、root motion、cache 取樣／插值與版本相容條件。
- 本體可重用部分與場景特有 bounds／路徑／受光分開；列出資源擁有者與 dispose 責任。
- 驗證有限值、速度／邊界、時間步長敏感度、暫停、循環接縫及真正 GLB／browser；程式測試不證明生物學正確。

比較或使用者選擇連到 [實驗模板](../production/templates/experiment.md)，不要只保存最終頻率。
