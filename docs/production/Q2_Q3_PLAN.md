## 目標與範圍

使用者 2026-09-27 的要求：
1. 一路做到 Q3 結束，包含後續驗收。
2. 水母要像「在水族館裡看到的那種感覺」，移動要更自然；研究並評估在畫面中加入「透明的虛擬水流」，讓水母的狀態與變化更直接地呈現。

### 和 MASTER 的衝突與本計劃的解讀

MASTER 明文禁止 aquarium appearance、glowing magic、colorful particles，並規定最多只能有一件不可能的事。因此本計劃這樣解讀：

- **要做**：水母本身的外觀與動態，要像在水族館觀察到的活體。逆光下傘緣柔亮、組織柔和散射、器官半透明、傘體會傾斜轉向，動作呈現「脈動、推進、滑行」的節奏。
- **不做**：把房間變成水族箱。不加水槽框、藍色水族燈、氣泡或彩色光。
- **虛擬水流**：歸在雪落海窗既有的「不可能現象」底下，也就是生物在室內的不可見水介質中游動。可視化方式只允許不發光、無彩度、只在受光處可見的手段。至少要做 A/B 讓使用者選，而且保留「不顯示水流」這個選項。
- 若使用者之後明確表示要偏離 MASTER（例如接受更明顯的水體感），就記進 [偏好](PREFERENCES.md)，並取代本段解讀。

## J 期：水母專案

研究報告：[jellyfish-realism-research.md](../biology/jellyfish-realism-research.md)（2026-09-27 完成）。J1–J4 的驗收以報告「實作分期與驗收」的數值為準，重點如下：
- 外觀：傘體無色，放射管、生殖腺是淡藕紫；放射管從實體 tube 改成下傘面的淡色帶。
- 運動：收縮占週期約 .20；允許 0–35° 的常態傾斜；轉向靠不對稱收縮加滑移，角速度上限約 .4 rad/s。
- 流場：量級維持 0.5–2 cm/s，重點是「讓它看得見」。尾流用每拍兩個 Lagrangian 渦環（starting／stopping）。
- 可視化：以「只在光錐內可見的 marine snow」為主、細塵為輔。折射扭曲和流線不採用：前者容易變成魔法感，後者違反寫實。因此 J4 的 A/B 改為「顆粒 vs 不顯示」，另加「顆粒密度」一個變因。

| # | 階段 | 內容 | 驗收 |
|---|---|---|---|
| J0 | 研究 | 真實運動資料、水族館外觀、水流、即時圖學做法、水流可視化選項 | 報告有可查來源，事實、近似與美術分開標示 |
| J1 | 外觀 | 傘體用 fresnel 邊緣加柔和內部散射，取代均勻灰；放射管變細變淡並有分叉；生殖腺改成半透明、柔和的淡紫粉；觸手受光、隨距離淡出；口腕要有柔軟體積，不再有摺紙折面 | 近看與場景內四時段；月夜不發光；和水族館參考照片並排比較 |
| J2 | 姿態與運動 | 取消「永遠朝上」，傘軸可以傾斜、轉向、偶爾翻轉；以不對稱收縮轉向；「收縮推進 → 滑行 → 回彈」節奏可辨識；頻率與推進比依研究數據校準 | 統計：傘軸傾角分布、每次脈動推進（以體長計）、轉向率；連拍與錄影 |
| J3 | 流場與耦合 | 背景流：慢速的大尺度迴旋，無散度；尾流：每次收縮產生一個衰減的渦環，推動附近的觸手、顆粒和其他生物；觸手和口腕對相對流速有反應 | 流場 divergence 測試；每個渦環的強度與衰減時間；耦合方向正確 |
| J4 | 流場可視化 | A/B：(a) 懸浮細塵沿流場移動、只在窗光內可見；(b) 加上極淡的折射扭曲；(c) 不顯示。脈動時要看得出細塵被推開 | 符合 MASTER（不發光、無彩色、受光處才可見）；效能；使用者選擇 |
| J5 | 裸海蝶 | 提高透射並補上頭錐（併入 Q3） | 近看 |

水母的所有數值都要標示來源等級：A 文獻實測、B 模型近似、C 美術。資料寫進 `docs/biology/aurelia-clione.md`。

## V 期：最終驗收

1. **9 景矩陣**：四時段、兩種畫質、桌面與直式畫面，固定 elapsed 和 seed。
2. **生物**：連拍、數值測試全部通過；防穿模、暫停、seed 重現。
3. **效能**：每景記錄 frame interval（p50／p95）、draw calls、triangles、GPU 記憶體，以及 GLB 和貼圖大小，和 main 基準比較。**超過 10% 的退步要說明或修正**。
4. **文件**：場景頁、生物頁、CAPABILITIES、PREFERENCES（使用者確認過的項目）、本頁的進度紀錄。
5. **檢視包**：把所有 before／after 整理成一頁可以瀏覽的比較頁，交給使用者做 G5 決定。
6. **分支處理**：開 PR 或合併、部署，一律由使用者拍板。

驗證的限制照舊：技術通過、browser 看到、使用者確認、實機、部署分開記錄。
